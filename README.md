## English

A Codex skill turning everyday photos into 3:4 minimal photo-collage posters: **real subject × flat color blocks × simple icons**.

### Core Rules

- **Person**: real photographic texture, natural skin, original clothing, with a clean cream-white cutout edge — never re-illustrated, posterized, or recolored.
- **Environment**: no full background; compress the scene into 1–3 large flat color blocks or brush strokes, plus 2–4 simple flat icons (bucket, shovel, leaf, road curve…).
- **Scene hint**: with the small thumbnail hidden, the color blocks and icons should still suggest where the photo was taken; over-abstraction and background copying both fail.
- **Layout**: subject forms a central visual island on a warm-white page — no full-bleed scenery; title sits centered below the subject, small and restrained.
- **Whitespace**: ~65–80% warm-white quiet space (flexible); one small original-photo thumbnail as visual evidence.

### Usage

Install as a Codex skill and invoke:

```text
$daily-photo-playground-illustrated
```

## 中文

[**English**](#english) | [**中文**](#中文)

一个把日常照片重构为「**真实人物 + 平面色块 + 极简图标**」3:4 极简摄影拼贴海报的 Codex skill。

### 核心规则

- **人物**：保持真实摄影质感、自然肤色与原本服装颜色，外圈加奶油白剪纸描边；不插画化、不 posterize、不为背景改色。
- **环境**：不绘制完整背景；从原图提取环境特征，压缩为 1–3 个大面积纯色色块/粗笔刷形状，配 2–4 个扁平图标（水桶、铲子、叶子、道路曲线等）暗示环境。
- **场景暗示**：隐藏缩略图后，色块与图标仍应能让人联想到照片发生在哪里；过度抽象与照搬背景均为失败。
- **布局**：人物与色块聚成中央视觉岛，不做满版风景；主标题在人物下方居中、小而克制。
- **留白**：暖白外页约 65–80% 低信息空间，比例可浮动；保留 1 个很小的原照片缩略图作视觉证据。

### 使用

安装为 Codex skill 后调用：

```text
$daily-photo-playground-illustrated
```
