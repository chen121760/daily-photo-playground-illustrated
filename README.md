## English

A Codex skill turning everyday photos into 3:4 editorial art: **photographic subject × illustrated environment**.

### Core Rules

- **Person**: real photographic texture, natural skin, original clothing — never re-illustrated, posterized, or recolored.
- **Environment**: remove the real background; redraw 2–5 elements as simplified, recognizable illustration — saturated for the scene, natural for the person.
- **Scene check**: with the photo window hidden, the scene must still be identifiable; over-abstraction and background copying both fail.
- **Geometry**: 0–3 supporting elements, sourced from the scene; no filler decoration.
- **Whitespace**: ~60–80% warm-white quiet space (flexible); one small original-photo window as visual evidence.

### Usage

Install as a Codex skill and invoke:

```text
$daily-photo-playground-illustrated
```

## 中文

[**English**](#english) | [**中文**](#中文)

一个把日常照片重构为「**真实摄影主体 × 插画化环境**」3:4 竖版作品的 Codex skill。

### 核心规则

- **人物**：保持真实摄影质感、自然肤色与原本服装颜色；不插画化、不 posterize、不为背景改色。
- **环境**：删除真实背景，从原图提取 2–5 个元素，重绘为简化但可识别的场景插画；环境可高饱和，人物保持自然。
- **场景识别**：隐藏原照片窗口后，仍应判断出照片发生在哪里；过度抽象与照搬背景均为失败。
- **几何**：仅 0–3 个辅助元素，且源自场景；不添加填空装饰。
- **留白**：暖白外页约 60–80% 低信息空间，比例可浮动；保留 1 个小原照片窗口作视觉证据。

### 使用

安装为 Codex skill 后调用：

```text
$daily-photo-playground-illustrated
```
