# daily-photo-playground-illustrated

> **Preserve the subject. Redraw the world.**
> **保留真实的人，重新绘制记忆中的世界。**

一个将日常照片重构为「真实摄影主体 × 插画化环境」的 Codex skill。
A Codex skill that reworks everyday photos into **photographic subject × illustrated environment** compositions.

它不会把整张照片统一画成插画，也不会把人物海报化——它保留真实的人，把背景重绘成可识别的场景插画。
It never turns the whole photo into one illustration, nor posterizes the person — it keeps the real subject and redraws the background as a recognizable scene.

最终得到一张介于摄影、插画与编辑设计之间的 3:4 竖版作品。
The result: a 3:4 vertical artwork between photography, illustration, and editorial design.

---

## Concept / 概念

> 保留照片里真实的人，重新绘制他们所处的世界。
> Keep the person in the photo real; redraw the world around them.

- 人物来自原照片，保持真实摄影质感、自然肤色与原本服装颜色。
  The person keeps real photographic texture, natural skin tones and original clothing.
- 环境（海、沙滩、树、街道、室内…）重绘为简化但可识别的插画。
  The environment (sea, beach, trees, streets, interiors…) is redrawn as simplified but recognizable illustration.
- 画面同时保留两件事：人真实存在于那个瞬间；地点已被重新组织成一种视觉记忆。
  The image keeps both: the person was really there, and the place has become a visual memory.

## Visual Language / 视觉语言

### Subject / 人物

- 保持真实摄影质感；禁止重新插画化、posterize、用色块替换肤色、为匹配背景改色。
  Keep photographic texture; never re-illustrate, posterize, block-color the skin, or recolor to match the background.
- 人物是画面中的 **photographic anchor**（摄影锚点）。

### Environment / 环境

- 不保留完整真实背景；从原照片提取 **2–5 个最有辨识度的元素**，重绘为平面色块、简化轮廓、低细节插画。
  Remove the full realistic background; extract 2–5 distinctive elements and redraw them as flat shapes, simplified silhouettes, low-detail illustration.
- 示例：海边 → 海面 / 地平线 / 沙滩 / 椰树 / 波浪；街道 → 道路 / 建筑轮廓 / 路灯 / 天际线；公园 → 草地 / 树冠 / 长椅 / 路径。
  e.g. beach → sea / horizon / sand / palms / waves; street → road / skyline / streetlights; park → grass / canopy / bench / path.
- 插画可以简化，但不应抽象到失去场景信息。
  Simplification is fine; losing the scene is not.

### Scene Recognition / 场景识别

隐藏小型原照片窗口后，仅看人物与重构环境，仍应判断出照片发生在哪里。
With the original-photo window hidden, the person + reconstructed environment should still tell where the photo was taken.

- 完全无法判断场景 → **过度抽象**（over-abstracted）
- 几乎复制真实背景 → **重构不足**（under-reconstructed）
- 目标：**recognizable, but reimagined**（可识别，但已被重新想象）

### Geometry / 几何（辅助）

- 0–3 个辅助几何元素，最好源自场景：波浪→弧线、地平线→横线、树冠→圆形色块、窗框→矩形、道路→斜线。
  0–3 supporting elements, ideally from the scene: waves→arcs, horizon→lines, canopy→circles, windows→rectangles, road→diagonals.
- 不要为填满空间添加无意义的装饰图形。
  No filler decoration.

## Composition / 构图

- 3:4 竖版；两级结构：暖白外部页面（留白、呼吸、编辑感）+ 中央重构区（人物、插画环境、原照片窗口、辅助几何、文字）。
  3:4 portrait; two-tier structure: warm-white outer page (whitespace, breathing, editorial feel) + inner composition (person, illustrated environment, photo window, support geometry, typography).
- 默认保留约 **60–80% 连续低信息空间**；这是灵活指标，不是机械门禁——环境叙事需要时可以让构图更饱满。
  ~60–80% quiet space by default; a flexible guideline, not a hard gate — the composition may grow fuller when the scene needs it.

## Color / 色彩

人物与环境采用两套不同的色彩逻辑 / Two separate color systems:

- **人物**：自然肤色、原始服装颜色、摄影中的真实明暗关系。
  **Subject**: natural skin, original clothing, true photo lighting.
- **环境**：可以大胆高饱和——钴蓝、群青、青、紫、品红、柠檬黄、梨绿、橙、番茄红。
  **Environment**: free to go saturated — cobalt, ultramarine, cyan, violet, magenta, lemon, lime, orange, tomato red.
- 重点不是统一画面颜色，而是让真实摄影主体与重新想象的插画世界鲜明而协调。
  The goal isn't one unified palette, but a vivid yet harmonious contrast between the real subject and the imagined world.

## Original Photo Window / 原照片窗口

保留 **1 个完整可读的小型原照片窗口**，作为「视觉证据」——那个真实瞬间原本的样子。
Keep one small, readable window of the original photo as **visual evidence** of how the moment really looked.

## Typography / 排版

- 文字进入构图但保持克制：用户提供的日期/地点、极短标题、一句情绪文本。
  Typography joins the composition, restrained: date/place (if provided), a very short title, one emotional line.
- 避免：大段文字、游离在画面之外的文字、无意义英文、文字层级压过人物与场景。
  Avoid: long text, floating labels, meaningless English, typography louder than the subject.

## Workflow / 流程

```text
PHOTO
→ PRESERVE SUBJECT        保留真实人物
→ REDRAW WORLD            重绘可识别的场景插画
→ EDITORIAL COMPOSITION   编辑排版：几何、原照片窗口、留白、文字
```

## Example / 示例

海边照片 → 真实摄影人物 + 大面积钴蓝海面 + 简化沙滩色块 + 插画树冠 + 波浪弧线 + 小型原照片 + 日期/地点 + 暖白留白。
Beach photo → real person + cobalt sea + simplified sand + illustrated canopy + wave arcs + small original photo + date/place + warm-white whitespace.

> 人物来自现实，环境来自记忆。
> People from reality. Environment from memory.

## Compared with the Original / 与原项目对比

fork 自 `luji12/daily-photo-playground`。

| Original 原项目 | Illustrated 本版本 |
| --- | --- |
| 主体海报化 / posterized subject | 主体保持摄影质感 / photographic subject |
| 环境高度抽象 / abstract environment | 环境保持可识别 / recognizable environment |
| 几何是核心视觉语言 / geometry-driven | 几何降为辅助 / geometry as support |
| 整体重新映射颜色 / global recoloring | 人物与环境分离配色 / separated palettes |
| graphic poster | photography × illustration |

它不是替代原项目，而是探索另一个方向：**如果不重新设计照片里的人，只重新设计他们身边的世界，会发生什么？**
It's not a replacement — it asks: *what if we redesign only the world around the person, not the person?*
